# Security Policy

If you believe you have found a security issue in Pharma-QMS, its workflows, or a Zeuthen product, report it privately to the QMS owner, Ulrik Zeuthen (GitHub `@Zeuthens`). TODO: add a dedicated security contact address.

Please do not open a public GitHub issue for unpatched vulnerabilities.

Include:

- affected component or file
- reproduction steps or proof of concept
- impact assessment
- any suggested remediation

Security events are handled under `SOP-021` Information Security Management.
